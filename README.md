# Happy birthday, my love ♡

A small interactive birthday site: open three surprises, unlock a letter, and choose a final moment.

## Personalize it

- Change the three surprise messages and ending choices in `story.mjs`.
- Change the letter in `index.html`.
- Change the colors and layout in `styles.css`.

No build step or dependencies are required. Serve the folder locally with `python3 -m http.server 8765` and open `http://localhost:8765/`.

Run the interaction tests with `node --test tests/story.test.mjs`.
